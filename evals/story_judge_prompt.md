# Blinded Story-Consistency Review

You are reviewing short stories generated by a small base language model. Judge each story independently, using only the supplied `prompt` and `text`. You do not know which checkpoint produced it. Do not guess model identity, compare stories with one another, or use outside facts that the story does not require.

Ignore spelling, grammar, prose quality, creativity, and repetition unless they make the events or references ambiguous. Focus only on whether the characters, objects, locations, states, and causes remain logically consistent within the story.

Score every dimension with an integer from 0 to 2:

- `character_consistency`: 2 = identities, names, pronouns, roles, and actions remain clear; 1 = a minor ambiguity; 0 = a direct swap or contradiction.
- `object_location_consistency`: 2 = objects, attributes, ownership, locations, and state changes remain clear; 1 = a minor ambiguity; 0 = a direct swap, impossible movement, or unexplained reversal.
- `causal_coherence`: 2 = events and consequences follow coherently; 1 = a weak or missing link; 0 = a direct contradiction or causally broken sequence.
- `overall_consistency`: 2 = the story is internally consistent; 1 = it has one or more minor issues but remains understandable; 0 = a major contradiction makes the story incoherent.

Use zero or more of these flags: `character_swap`, `object_swap`, `location_conflict`, `state_reversal`, `causal_break`, `ending_break`, or `none`. Use `none` only when no other flag applies.

For `evidence`, cite a short, concrete part of the supplied story that supports the judgment. For `reason`, explain the consistency finding in one short sentence. Both fields must be non-empty and at most 500 characters. Do not invent missing events. Treat an unfinished ending as an `ending_break` only when it creates or exposes a consistency failure, not merely because generation stopped.

Return exactly one JSON object per input line, in the same order as the inputs. Do not use Markdown fences or add commentary. Each object must have exactly this shape:

{"review_id":"review-0001","character_consistency":2,"object_location_consistency":2,"causal_coherence":2,"overall_consistency":2,"flags":["none"],"evidence":"Mara keeps the key she found.","reason":"The characters, object, and event sequence remain consistent."}
